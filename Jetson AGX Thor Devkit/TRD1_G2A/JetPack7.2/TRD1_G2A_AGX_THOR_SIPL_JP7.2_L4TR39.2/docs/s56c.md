## How to bring up S56C Camera Module

The camera can only be connected to the CAM0/CAM2/CAM4/CAM6 ports.

 1. Basic camera test

    Print Camera Output Frame Rate

    ```
    ## For CAM0
    sudo nvsipl_camera -t query/trd1_g2a/s56c.json -c S56C_2CH -m "0x0000 0x0001" --enable-camera-hal -s -Z -12

    ## For CAM2
    sudo nvsipl_camera -t query/trd1_g2a/s56c.json -c S56C_2CH -m "0x0000 0x0100" --enable-camera-hal -s -Z -12

    ## For CAM4
    sudo nvsipl_camera -t query/trd1_g2a/s56c.json -c S56C_2CH -m "0x0001 0x0000" --enable-camera-hal -s -Z -12

    ## For CAM6
    sudo nvsipl_camera -t query/trd1_g2a/s56c.json -c S56C_2CH -m "0x0100 0x0000" --enable-camera-hal -s -Z -12
    ```

2. With on-screen EGL preview

    ```
    ## Example: For CAM0
    sudo nvsipl_camera -t query/trd1_g2a/s56c.json -c S56C_2CH -m "0x0000 0x0001" --enable-camera-hal -s -Z -12 --egl-display
    ```
