## How to bring up S56C Camera Module

The camera can only be connected to the CN7 and CN5 ports.

 1. Basic camera test

    Print Camera Output Frame Rate

    ```
    ## For CN7 CAM0
    sudo nvsipl_camera -t query/sg4a_nonx_g2y_a1/s56c.json -c S56C_2CH -m "0x0001" --enable-camera-hal -s -Z -12

    ## For CN5 CAM2
    sudo nvsipl_camera -t query/sg4a_nonx_g2y_a1/s56c.json -c S56C_2CH -m "0x0100" --enable-camera-hal -s -Z -12
    ```

2. With on-screen EGL preview

    ```
    ## Example: For CN7 CAM0
    sudo nvsipl_camera -t query/sg4a_nonx_g2y_a1/s56c.json -c S56C_2CH -m "0x0001" --enable-camera-hal -s -Z -12 --egl-display
    ```

3. Show EEPROM data (Internal parameters)

    Note: For stereo camera systems, EEPROM data must be read from one camera at a time. Reading the EEPROMs of multiple cameras simultaneously may result in incorrect or corrupted data.

    ```
    ## Example: For CAM0
    sudo nvsipl_camera -t query/sg4a_nonx_g2y_a1/s56c.json -c S56C_2CH -m "0x0001" --enable-camera-hal -s -Z -12 -e
    ```
