## SENSING Camera Drivers for Jetson AGX Orin Developer Kit adapt with SG10A-AGON-G2M-A1

#### Supported Jetpack

* Jetpack 7.2

#### Hardware Connect

* Using adapt board connect up to 10 cameras
  ![alt text](<../../Picture/SENSING Deserializer Adapt Board/SG10A-AGON-G2M-A4.jpg>)

#### Power Supply

* SG10A-AGON-G2M-A4 adapt board need to be powered by 12V.

#### Camera Version Support

| Type | Camera                      | Jetpack 7.2 | 
| ---- | --------------------------- | ----------- | 
| YUV  | SG2-AR0233C-5200-G2A-Hxxx   | YES         | 
| YUV  | SG3S11AFSK                  | YES         | 
| YUV  | SHW3H(3MP/H120UA)           | YES         | 
| YUV  | SHF3L(3MP/H190XA)           | YES         | 
| YUV  | SG8-OX08DC-5300-G2G-Hxxx    | YES         | 
| RAW  | SHW3G                       | YES         | 
| RAW  | SHW5G                       | YES         | 
| RAW  | Astra S56C                  | YES         |
