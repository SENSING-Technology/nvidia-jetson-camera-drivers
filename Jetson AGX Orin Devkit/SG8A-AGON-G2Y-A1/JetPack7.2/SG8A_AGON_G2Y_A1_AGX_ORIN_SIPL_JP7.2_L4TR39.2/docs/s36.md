## How to bring up S36 Camera Module

The camera can only be connected to the CAM0/CAM2/CAM4/CAM6 ports.

 1. Supported Camera Specifications

    | Camera Model | GMSL Rate | Resolution | Frame Rate |
    | :--- | :---: | :---: | :---: |
    | `S36` | 6G | 1920x1536 | 30 fps |
    | `S36` | 6G | 1920x1080 | 30 fps |

    **Note:** The module firmware must match the resolution selected in the JSON
    configuration.


 2. Update the JSON configuration file

    **Target file:** `query/sg8a_agon_g2y_a1/s36.json`

    **Available configurations:**

    * `S36_2CH_1920X1536_30FPS`: 1920x1536, multi-module
    * `S36_2CH_1920X1080_30FPS`: 1920x1080, multi-module
    * `S36_1920X1536_30FPS`: 1920x1536, single module
    * `S36_1920X1080_30FPS`: 1920x1080, single module

    Select the configuration that matches the camera module firmware and the number of modules.


 3. Basic camera test

    Print Camera Output Frame Rate (for modules with 1920x1536 output firmware)

    ```
    ## For CAM0
    sudo nvsipl_camera -t query/sg8a_agon_g2y_a1/s36.json -c S36_2CH_1920X1536_30FPS -m "0x0000 0x0001" --enable-camera-hal -s -Z -012R

    ## For CAM2
    sudo nvsipl_camera -t query/sg8a_agon_g2y_a1/s36.json -c S36_2CH_1920X1536_30FPS -m "0x0000 0x0100" --enable-camera-hal -s -Z -012R

    ## For CAM4
    sudo nvsipl_camera -t query/sg8a_agon_g2y_a1/s36.json -c S36_2CH_1920X1536_30FPS -m "0x0001 0x0000" --enable-camera-hal -s -Z -012R

    ## For CAM6
    sudo nvsipl_camera -t query/sg8a_agon_g2y_a1/s36.json -c S36_2CH_1920X1536_30FPS -m "0x0100 0x0000" --enable-camera-hal -s -Z -012R
    ```

    For modules with 1920x1080 output firmware, replace the configuration name:
    `S36_2CH_1920X1536_30FPS` -> `S36_2CH_1920X1080_30FPS`


 4. With on-screen EGL preview

    ```
    ## Example: For CAM0
    sudo nvsipl_camera -t query/sg8a_agon_g2y_a1/s36.json -c S36_2CH_1920X1536_30FPS -m "0x0000 0x0001" --enable-camera-hal -s -Z -012R --egl-display

    ```


 5. Show EEPROM data (Internal parameters)

    Note: For stereo camera systems, EEPROM data must be read from one camera at a time. Reading the EEPROMs of multiple cameras simultaneously may result in incorrect or corrupted data.

    ```
    ## Example: For CAM0
    sudo nvsipl_camera -t query/sg8a_agon_g2y_a1/s36.json -c S36_2CH_1920X1080_30FPS -m "0x0000 0x0001" --mixed-yuv-output --enable-camera-hal -s -Z -e
    ```
